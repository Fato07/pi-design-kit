# DESIGN.md Template

Use this structure for project-owned design systems.

```markdown
# <Product or Brand> DESIGN.md

> One-line design thesis: audience, tone, and visual posture.

## 1. Visual Theme & Atmosphere

Describe mood, density, design philosophy, and what the interface should feel like.

## 2. Color Palette & Roles

List semantic colors with hex values and exact roles: canvas, surface, primary, text, muted text, border, success, warning, destructive.

## 3. Typography Rules

Define font families, hierarchy, weights, line heights, letter spacing, and when each text role is used.

## 4. Component Stylings

Specify buttons, cards, inputs, navigation, modals, tables, charts, badges, empty states, and states such as hover/focus/disabled.

## 5. Layout Principles

Define spacing scale, grid behavior, section rhythm, max widths, density rules, and whitespace philosophy.

## 6. Depth & Elevation

Define shadows, borders, overlays, blur, layering, z-index principles, and surface hierarchy.

## 7. Do's and Don'ts

Concrete guardrails and anti-patterns. Include examples of what would feel off-brand.

## 8. Responsive Behavior

Breakpoints, mobile-first adjustments, touch target minimums, collapsing strategy, and typography changes.

## 9. Agent Prompt Guide

Short instructions an AI agent can follow quickly: key tokens, default component choices, and examples of prompts.
```
